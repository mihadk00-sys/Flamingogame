# 🦩 Flamingo Game

A lightweight 2D arcade game built with Java Swing, inspired by Flappy Bird. 
Control a flamingo as it flies through a side-scrolling world, dodging 
green obstacles to rack up points. Simple physics, keyboard controls, 
and a clean game loop make this a fun mini-project for learning Java 
game development fundamentals.

## Features
- Gravity-based flight mechanics
- Procedurally spawned obstacles
- Real-time collision detection
- Score tracking
- Restart on game over

## Controls
- **SPACE** — Jump / Flap
- **R** — Restart after game over

## Tech Stack
Java, Java Swing (AWT/Graphics2D)

## Run It
```bash
javac FlamingoGame.java
java FlamingoGame
```
